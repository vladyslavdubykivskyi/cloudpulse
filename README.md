# CloudPulse — IT Infrastructure Status Dashboard

Сучасна вебсторінка моніторингу статусу хмарної інфраструктури, створена на чистому **HTML5** та **CSS3** без використання JavaScript.

🔗 **Жива версія сайту (GitHub Pages):** [https://vladyslavdubykivskyi.github.io/cloudpulse/](https://vladyslavdubykivskyi.github.io/cloudpulse/)

---

## Основний функціонал та технічні рішення

- **Семантична верстка (HTML5):** логічна структура сторінки (`<header>`, `<main>`, `<section>`, `<article>`, `<table>`, `<form>`, `<footer>`) за методологією БЕМ.
- **Компонентна дизайн-система:** єдиний набір CSS-змінних у `:root` (кольорова палітра темної теми, шкала відступів із кроком 8 px, радіуси заокруглення та тіні).
- **Адаптивний інтерфейс (RWD):** коректне відображення на екранах від 320 px до 1920 px із трьома контрольними точками (`900px`, `768px`, `480px`) та мобільним бургер-меню на чистому CSS (*Checkbox Hack*).
- **Мультимедіа та оптимізація:** інтеграція векторної графіки SVG, стиснених зображень WebP та фонового зацикленого HTML5-відео з автоматичним кадруванням `object-fit: cover`.
- **Інтерактивні форми та таблиці (0 рядків JS):** семантична таблиця SLA з локальним горизонтальним скролом на мобільних пристроях та форма підписки на сповіщення з 7 типами полів і нативною браузерною валідацією.
- **CSS3-анімації та доступність (WCAG 2.1):** плавні переходи `transition`, апаратно прискорені трансформації `transform`, каскадна поява `@keyframes`, клавіатурна навігація (`Skip to main content`, `:focus-visible`) та повна підтримка `@media (prefers-reduced-motion: reduce)`.
